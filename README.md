# android_hardware_samsung_slsi-cm_exynos5420

Implementações em C/C++ dos módulos de abstração de hardware (HAL) para suporte a câmera, aceleração gráfica (gralloc) e áudio em SoCs Exynos 5420.

## 🛠️ Tecnologias

- **C**
- **C++**
- **Android HAL**
- **Exynos 5420 Drivers**

## 📂 Estrutura do Projeto

- `gralloc/`: Alocador de memória gráfica.
- `libcamera/`: Driver HAL de câmera.
- `exynos5420.mk`: Configurações de compilação da HAL.
